# 夜间自主执行计划（Mod 化架构版）：游戏能玩 + 明天改任何东西都轻松

## 回答你的问题：能不能轻松改？——能，架构保证如下

**核心原则：引擎和内容彻底分离。** 引擎代码（基于 PvZ Travel 开源版改造）不含任何具体角色数据；所有内容住在 `data/` 目录下，每样东西 = 一个文件夹。改技能、换形象、换地图、加怪、加关卡，都不用碰引擎。

### 目录结构（你明天打交道的全部）

```
game/
├─ data/                      ← ★ 你改东西只动这里
│  ├─ characters/             ← 每个 AI 娘一个文件夹
│  │  └─ dabafei-eat/         （例：吃白饭大肥鱼）
│  │     ├─ config.js         数值：费用/血量/攻击/冷却/卡片图标
│  │     ├─ skills.js         技能：普攻/被动/特殊/能量豆（固定接口，照抄现成例子改）
│  │     └─ images/           立绘+卡片图（你截图同名替换=换形象）
│  ├─ zombies/                ← 每个僵尸一个文件夹（结构同上）
│  │  └─ pop-ad/  normal/  hallucination/ ...
│  │     ├─ config.js         数值：血量/速度/啃咬
│  │     ├─ behavior.js       行为钩子：移动/啃咬/特殊行为（可选）
│  │     └─ images/           长相（换图=换长相）
│  ├─ levels/                 ← 每关一个文件
│  │  └─ level-1.js           波次表（每波出什么怪几只）+ 解锁卡列表 + 主题引用
│  ├─ themes/                 ← 地图皮肤
│  │  └─ day-lawn/            背景图/格子颜色/UI 配色（换图=换地图长相）
│  ├─ card-pool.js            ← 每关卡片栏出哪些卡（增删角色改这里）
│  └─ global.json             ← 全局数值：token 掉落率/显卡掉率/波次强度系数
└─ engine/                    ← 引擎核心（永远不用动）
```

### 你列的 4 件事分别怎么实现（都有现成例子可抄）

1. **加僵尸/梗怪**：复制任意一个僵尸文件夹 → 改 config 数值 → （可选）在 behavior.js 挂行为组件（引擎内置组件库：眩晕/隐身/无敌帧/跳跃/分裂/减速/剥装/变形/周期停顿……已实现的行为都是组件，一行挂载）→ 放图 → 在关卡波次表里写它的名字。5 分钟一只。
2. **加关卡**：复制一个 level 文件 → 改波次数组（第几波、什么怪、几只、间隔秒数，纯数据）+ 解锁卡列表 → 自动出现在选关界面。
3. **加角色**：复制任意角色文件夹 → 改数值和技能（skills.js 是固定 4 个钩子：onPlant 种下时/onTick 每帧/onHit 命中时/onUltimate 能量豆，8 张现成卡就是 8 个例子）→ 放图 → 加入 card-pool。
4. **加其他东西**：全局数值全在 global.json（token 经济/掉率/强度系数，调平衡改这里）；新视觉行为做成组件库扩展。

README 会写一份《改东西手册》：每个需求对应"动哪个文件、抄哪个例子"，配实例。
