# 《AI娘大战僵尸》

一个用 AI 圈流行梗重制的《植物大战僵尸》同人网页游戏。**阳光变成了 Token，植物变成了 AI 娘，僵尸里混进了网络故障怪。**

> 基于开源项目 [PvZ Travel 开源版](https://github.com/jiangnangame/The-Open-Source-Version-Of-PvZ-Travel)（江南游戏开发社，长江协议）改造，非盈利同人作品，所有二创形象版权归原画师所有，侵删。

---

## 怎么玩

**在线直接玩**：[https://nbwzb666.github.io/ai-girls-vs-zombies/](https://nbwzb666.github.io/ai-girls-vs-zombies/)（已发布，可直接分享给别人）

**本地**：双击 `game/index.html`（推荐 Chrome/Edge）。  
**快速演示**：在线/本地地址后加 `?lvl=AIGirls1&demo=1` 可看自动种植+自动放大招的演示。

- 5 行 × 9 列服务器草坪，僵尸从右侧按波次进攻
- 资源是 **Token**：天上会掉，吃白饭大肥鱼会产
- 撑过全部波次 = 胜利；僵尸突破 = 该行**防火墙**（原割草机）清场一次，防火墙用完再破 = 失败
- 战斗中会掉落**显卡**（绿色），拾取后点击场上一名 AI 娘释放她的大招

## 僵尸阵容

经典三件套（普通/路障/铁桶）保留 + 5 种梗怪：

| 敌人 | 梗 | 机制 |
|---|---|---|
| 弹窗广告僵尸 | 弹窗广告挡路 | 顶弹窗盾飘过你的前排，打掉盾后落地 |
| 路由器僵尸 | "被路由到 Luna" | 啃 AI 娘使其降智 10s（攻速 -40%） |
| 幻觉僵尸 | "它在幻觉" | 半透明，远程 35% 打空 |
| 转圈加载僵尸 | 网页转圈 | 速度快，每 3s 转圈 1s（无敌） |
| 版本更新巨人（Boss） | 强制更新恐惧 | 每损 25% HP 无敌+变强 |

## 目录结构（改东西只动这些）

```
game/
├─ js/ai-chars.js      ★ 8 张卡全部定义（每张卡一个块，含梗注释）
├─ js/ai-zombies.js    ★ 5 只梗怪定义
├─ js/ai-ultimate.js   ★ 显卡大招系统 + 8 个大招 + 小千问
├─ js/ai-patch.js      ★ 入口/关卡链/token换皮/demo模式
├─ modal/Level/AIGirls1~3.js  ★ 三个关卡（波次表+出怪+卡片）
├─ images/AIGirls/     ★ 所有自绘素材（角色/子弹/token/显卡）
├─ tools/gen_ai_art.py ★ 角色素材生成器（改配置重跑=换形象）
└─ （其余为 PvZ Travel 引擎，不需要动）
```

**详细操作见 [docs/改东西手册.md](docs/改东西手册.md)**——加角色/加僵尸/加关卡/改数值/换形象/换地图，每件事都有步骤有例子。
