# 改东西手册（你要的 4 件事 + 更多）

> 原则：**加东西 = 加文件/加一个定义块**，永远不用碰引擎。

## 1. 增加僵尸/梗怪

**例子：加一只"验证码僵尸"（要滑一下滑块才走得动）**

1. 打开 `game/js/ai-zombies.js`，复制任意一只怪的块，例如路由器僵尸：

```js
var oCaptchaZombie = InheritO(oZombie, {       // ← 继承普通僵尸=白板起步；继承 oConeheadZombie=自带护甲
  EName: "oCaptchaZombie",                      // ← 全局唯一内部名（o 开头）
  CName: "验证码僵尸",                          // ← 显示名
  HP: 300,                                      // 血量（普通僵尸=200，铁桶=1300）
  Lvl: 2,                                       // 图鉴等级（1普通 2精英 3Boss）
  NormalAttack(zid, pid, x) {                   // ← 可选：啃咬时的钩子
    // 这里写它啃到植物时发生什么（参考路由器僵尸的降智）
    return CZombies.prototype.NormalAttack.call(this, zid, pid, x);
  }
});
```

2. 进关卡出怪表（`modal/Level/AIGirls2.js`）：
   - `ZName: [...]` 里加 `oCaptchaZombie`
   - `AZ: [[oCaptchaZombie, 2, 4]]` = 第 4 波起出现、权重 2
3. （可选）换形象：见《素材替换指南》第 3 节

**可挂的现成行为**（在定义块里覆写方法即可）：
- `getPea` 受远程攻击时（幻觉僵尸在这做的 35% 闪避）
- `getHit0` 受伤时（转圈僵尸在这做的无敌）
- `BirthCallBack` 出生时（幻觉僵尸在这做的半透明；写 `oSym.addTask` 循环可做周期行为）
- `OSpeed/Speed` 移速、`Attack` 啃咬力

## 2. 增加关卡

**例子：加第 4 关"深夜机房"**

复制 `modal/Level/AIGirls3.js` 为 `AIGirls4.js`，改三处：

```js
oS.Init({
  PName: [oChiBaiFan, /* ...这关可用的卡 */],
  ZName: [oZombie, oUpdateGiant /* ...这关的怪 */],
  SunNum: 300,                          // 开局 Token
  LevelName: "深夜机房 2-1 不眠之夜",    // 关卡名
  StartGameMusic: "Bgm_Marsh_Fight",    // 换背景音乐（audio/ 目录里挑）
  backgroundImage: "images/interface/Marsh.webp",  // ← 换地图背景！
}, {
  AZ: [[oZombie, 5, 1], [oLoadingZombie, 3, 3]],   // 出怪表：[怪, 权重, 起始波]
  FlagNum: 12,                                      // 总波数
  FlagToSumNum: { a1: [3, 5, 8], a2: [1, 2, 4, 6] } // 波次强度曲线（a2 数组=梯度）
});
```

然后在 `js/ai-patch.js` 的 `NextLevel` 里把 `AIGirls3 → AIGirls1` 改成 `AIGirls3 → AIGirls4`。
浏览器直接访问 `index.html?lvl=AIGirls4` 测试。

## 3. 增加角色人物（AI 娘）

**例子：以后把 Kimi 加回来**

在 `game/js/ai-chars.js` 末尾加一个块（GPT龙娘的完整注释版就是模板）：

```js
/* ============ Kimi（月之暗面）—— 定位 ============
 * 梗：……
 * 素材目录：images/AIGirls/kimi/ */
oKimi = InheritO(CPlants, {
  EName: "oKimi",
  CName: "Kimi",
  width: 75, height: 75,
  beAttackedPointR: 51,
  SunNum: 150,                    // 费用
  HP: 300, coolTime: 10,
  AttackGif: 5, BulletGif: 3,     // PicArr 里的索引（照抄即可）
  PicArr: ["images/AIGirls/kimi/card.png",          // 0 卡片图
           "images/AIGirls/kimi/static.png",        // 1 静态
           "images/AIGirls/kimi/idle.png",          // 2 本体
           "images/AIGirls/bullets/star.png",       // 3 子弹
           "images/Plants/PeaBulletHit0.webp",      // 4 命中特效
           "images/AIGirls/kimi/attack.png"],       // 5 攻击姿态
  Tooltip: "一句话说明",
  Story: "梗的介绍（图鉴里看）",
  PrivateBirth(self) { /* 可选：种下时的初始化（循环/召唤写这里） */ },
  NormalAttack(zid) {             // 普攻（引擎自动触发，有敌人进入射程就调）
    if (!aiCanShoot(this, 1200)) return;    // ← 攻速节流，1200=1.2秒/发
    let self = this;
    oSym.addTask(60, _ => {
      CustomBullet(oBullet25, [self.PicArr[3]],   // ← 弹的构造器决定伤害（oBullet15/20/25/40/60 现成）
        self.AttackedLX, self.pixelTop + 15, self.R);
    });
  }
});
```

然后：关卡 `PName` 里加 `oKimi`；大招在 `js/ai-ultimate.js` 的 `aiULT` 表里加一行 `oKimi(p) {...}`；形象见下。

**专属子弹**（想自定义伤害/速度，文件顶部照抄一行）：
```js
oBulletKimi = InheritO(oPeaBullet, { EName: "oBulletKimi", Attack: 30, Speed: 6 }),
```

**已有弹表**：oBullet15/18/20/25/40/60、金光(upstream)、miss/crit(GPT方差)、pot盆、quill羽毛、claw猫爪、star星

## 4. 改数值/平衡

| 想改什么 | 动哪里 |
|---|---|
| 卡片费用/血量/冷却 | `ai-chars.js` 对应卡块的 `SunNum/HP/coolTime` |
| 攻击力/攻速 | 卡块 `NormalAttack` 里 `aiCanShoot(this, 毫秒)` 和子弹构造器 |
| 僵尸强度 | `ai-zombies.js` 的 `HP/Attack/OSpeed`；关卡 `AZ` 权重 |
| 波次数量/强度 | 关卡文件 `FlagNum/FlagToSumNum` |
| 开局 Token | 关卡文件 `SunNum` |
| 天降 Token 频率 | 引擎 `AutoProduceSun(50)` 参数（main.js DefaultStartGame 内，如需改问夜间助手） |
| 显卡掉落频率 | `ai-ultimate.js` 的 `gpuLoop`（60000+random*30000 毫秒） |

## 5. 换角色形象（两种方式）

- **方式 A（推荐）**：改 `tools/gen_ai_art.py` 里该角色的绘制函数/颜色 → 运行 `python tools/gen_ai_art.py` 全部重生成
- **方式 B**：手动放图。把 PNG 按下表文件名放进对应目录即自动生效：
  - `images/AIGirls/<角色>/card.png`（215×258 卡片）
  - `.../idle.png`（75×75 站立）`.../attack.png`（75×75 攻击）
  - 静态图 `static.png`、产币 `produce.png`（吃白饭专用）

## 6. 换地图长相

关卡文件加 `backgroundImage: "images/interface/xxx.webp"`。
想完全自定义：放一张 900×600 背景图到 `images/interface/`，引用它。格子配色在 `css/ui.css`（夜间未动，如需改问夜间助手）。
