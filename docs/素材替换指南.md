# 素材替换指南（用你找的图换掉程序绘制的 Q 版）

> 现在所有角色形象都是夜间用 Python 程序绘制的（风格统一但简笔画）。
> 引擎按**文件路径**引用图片——你放一张同名图进去就自动替换，**不用改任何代码**。

## 1. AI 娘角色图（最重要）

每个角色一个目录，需要的文件：

| 文件 | 尺寸 | 用途 | 备注 |
|---|---|---|---|
| `card.png` | 215×258 | 卡片栏大图 | 底部 44px 会被名字条盖住，主体放上半部 |
| `idle.png` | 75×75 | 站在草坪上的形象 | **透明底 PNG**；脚贴底边 |
| `attack.png` | 75×75 | 攻击姿态 | 可以和 idle 同图 |
| `static.png` | 75×75 | 静止贴图 | 可以和 idle 同图 |
| `produce.png` | 75×75 | 产币动作 | 仅吃白饭大肥鱼需要 |

目录对照（改哪个角色放哪个目录）：

```
game/images/AIGirls/
├─ dabafei-eat/     吃白饭大肥鱼   （特征：深蓝长发+鲸尾+女仆围裙+端白碗）
├─ dabafei-pot/     铁盆大肥鱼     （特征：同上+头顶不锈钢铁盆）
├─ dabafei-relay/   中转站大肥鱼   （特征：同上+路由器/网线）
├─ gpt-luna/        GPT龙娘        （特征：白发+绿龙角+龙翼）
├─ claude-ojou/     Claude大小姐   （特征：橘发+虎耳+红印章）
├─ doubao/          豆包           （特征：圆滚滚黄豆子+呆萌脸）
├─ hajimi/          Gemini哈基米   （特征：猫耳(Google四色)+香蕉）
├─ qwen/            千问大小姐     （特征：紫发+星饰）
└─ qwen-minion/     小千问随从     （千问的缩小版）
```

**截图哪里找**：B 站搜"AI娘全家桶""琵琶行AI天团""GPT龙娘""大肥鱼"——截图后裁成透明底即可（不会抠图就把图发给夜间助手，我写脚本批量抠）。

**大肥鱼现成素材**：GitHub 仓库 `the-beating-light-of-the-nail/deepseek-chan-meme-pack` 有表情包合集可挑。

## 2. 僵尸换皮（梗怪目前用的是原版僵尸图）

僵尸图在 `game/images/Zombies/<怪名>/` 下（引擎原有结构）。我们的梗怪当前**继承哪只怪就用哪套图**：

| 我们的梗怪 | 当前用的图（继承自） | 换皮方法 |
|---|---|---|
| 弹窗广告僵尸 | `Zombies/BalloonZombie/`（气球僵尸） | 把气球图换成"弹窗广告牌"PNG |
| 路由器僵尸 | `Zombies/Zombie/`（普通僵尸） | 换成"背路由器的僵尸" |
| 幻觉僵尸 | `Zombies/Zombie/`（代码强制半透明） | 换成残影风僵尸（半透明代码已写好会自动叠加） |
| 转圈加载僵尸 | `Zombies/Zombie/` | 换成"头顶转圈图标"僵尸 |
| 版本更新巨人 | `Zombies/Gargantuar/`（巨人） | 换成"扛进度条"巨人 |

僵尸图规格较大（216×164，人物居中偏右），替换时保持同尺寸即可。

## 4. 一键重生成程序绘制版

```bash
cd game
python tools/gen_ai_art.py
```

生成器是"配置驱动"的：每个角色的发型/颜色/特征物都是独立函数（`draw_dabafei`/`draw_gpt`/...），改颜色改装饰后重跑即可，适合快速迭代不同配色。
